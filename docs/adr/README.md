its context, the decision made, and its consequences.

## ADR Template

```markdown
# ADR-###: Title

## Status
Proposed / Accepted / Deprecated / Superseded

## Date
YYYY-MM-DD

## Decision Makers
List of stakeholders

## Context
The issue or problem motivating this decision.

## Decision
The chosen solution.

## Consequences
Positive and negative outcomes of this decision.

## Alternatives Considered
Other options evaluated and why they were rejected.
```
